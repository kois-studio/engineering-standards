# Agent Workflows

These workflows define what an agent must do after the session mode is selected.

- [Project bootstrap](project-bootstrap.md) — prepare an existing project for future AI development.
- [Project design](project-design.md) — define a not-yet-started or early-stage project.
- [Standards maintenance](standards-maintenance.md) — improve this repository’s shared standards system.

The workflows are complementary to the standards. They describe agent behavior and required outputs; the standards describe the engineering rules those outputs assess or adopt.
