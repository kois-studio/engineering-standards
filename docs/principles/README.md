# Engineering Principles

These principles provide durable direction for the standards and profiles in this repository.

1. **Optimize for durable clarity.** Prefer structures and explanations that remain understandable as people, tools, and requirements change.
2. **Prefer explicit and enforceable conventions.** A small rule that can be understood and checked is more useful than vague advice.
3. **Keep the source of truth close to the thing it describes.** Shared policy belongs here; project facts belong in the project repository.
4. **Make exceptions visible.** A justified exception is healthier than an undocumented divergence.
5. **Prefer boring consistency over unnecessary novelty.** Choose familiar, coherent approaches unless a different choice has a clear benefit.
